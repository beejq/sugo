# **SUGO**

**A game project for our subject in **Software Engineering 2**, at **Ateneo de Naga University** showcased in the **Software Festival 2025** during the **Ateneo Arts and Algorithm Festival** held on October 13-14, 2025, at Xavier Hall.**

Sugo is a 2D-platformer game where you have to first memorize a bunch of ingredients and race with time to get into the *tindahan* represented as the finish line, after reaching it you have to buy the ingredients by clicking the correct memorized ingredients.

The game is created using the game engine Godot 4, using GDScript as the main programming language.

- Won 2nd place as the best project
